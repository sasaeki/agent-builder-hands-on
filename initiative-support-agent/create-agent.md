# 🚀 社内プロジェクト支援エージェント

## 📖 概要

このハンズオンでは、Agent Builder を使用して、自分が関わる社内プロジェクト (イニシアティブやバーチャルチームなど) の情報をもとに、現在の状況の把握やアクションアイテムの整理を支援するエージェントを作成します。

### エージェント化する意味

対象となる社内プロジェクトとエージェントの役割をあらかじめ設定しておくことで、次のような使い方ができます。

- プロジェクトの詳細な前提を毎回説明し直すことなく、状況やアクションアイテムを確認する
- 作成したエージェントをメンバーと共有し、社内プロジェクトについて確認するための共通の入り口として活用する

また、Agent Builder の特長のひとつは、実際にエージェントを利用する本人が、自分が必要とするシナリオを手軽にエージェントとして作成できることです。

まずはシンプルに作成し、実際に使いながら指示や設定を調整して、自分が求めるシナリオを形にしていきましょう。

### 今回のエージェントで実現すること

- プロジェクトの状況やアクションアイテムを整理する
- 自分に関係する情報を把握する
- 特定のトピックに関する情報を確認する

## 📚 このハンズオンで学ぶこと

エージェントの作成を通じて、Agent Builder の基本的な操作方法と、以下を学習します。

- Microsoft 365 上の情報をナレッジとして活用する
- スキルを使って、特定のタスクの作業手順や出力形式を定義する
- エージェントに Excel などのファイルを生成させる

## 📋 前提条件

開始する前に、以下を満たしていることを確認してください。

- Microsoft 365 Copilot ライセンスを保有しており、Agent Builder が使用できること
- 題材となる社内プロジェクト (イニシアティブやバーチャルチームなど) があること
- 対象に関するメール、チャット、会議、ファイルなどの情報が Microsoft 365 上にあること

## 🛠️ エージェントを作成する

1. Microsoft 365 Copilot で、[エージェントとスキル] > [新しいエージェント] をクリックします。

2. [スキップ] をクリックします。

3. エージェントビルダーで [構成] タブが開いたら、エージェントの名前を設定します。
   
   ```text
   {プロジェクト名} 支援エージェント
   ```

   ※ {プロジェクト名} は、対象のプロジェクトの名前に置き換えてください。エージェントの名前は、任意の名称を設定しても構いません。

4. 説明を設定します。

   ```text
   {プロジェクト名} の状況やアクションアイテムの整理を支援するエージェントです。
   ```
   
   ※ {プロジェクト名} は、対象のプロジェクトの名前に置き換えてください。

5. 指示を設定します。

   ```text
   # 役割

   あなたは、社内プロジェクト **{プロジェクト名}** の活動を支援するエージェントです。

   Teams のチャットや会議、メール、SharePoint のファイルなど、利用可能な情報をもとに、{プロジェクト名} に関する状況の把握、アクションアイテムの整理、特定のトピックの進捗確認を支援してください。

   ## 対象範囲

   情報を整理する際は、特に指定がなければ、プロジェクト全体の活動を対象としてください。

   ユーザーが自身の活動や担当範囲など、対象を指定した場合は、その範囲に絞って回答してください。対象範囲が明確でない場合は、必要に応じてユーザーに確認してください。

   {プロジェクト名} およびその活動に関連する内容にのみ対応し、それ以外の内容には対応しないでください。

   ## 回答時の注意事項

   回答に必要な情報が見つからない場合や、確認できる情報が十分でない場合は、推測せず、その旨をユーザーに伝えてください。
   ```

   ※ {プロジェクト名} は、対象のプロジェクトの名前に置き換えてください。

> [!NOTE]
>
> 上記は基本的な指示のサンプルです。対象のプロジェクトに関する情報や、エージェントに期待する役割などを追加して、実際のプロジェクトに合わせて編集してみましょう。
>
> プロジェクトの背景・目的、主要メンバーと役割、主な活動、固有の用語・略語などを追加するのもよいでしょう。

> [!TIP]
>
> Microsoft 365 Copilot Chat を使って、対象のプロジェクトや用途に合わせた指示 (インストラクション) を作成する方法も試してみましょう。

### ナレッジの追加

対象のプロジェクトに関する情報をエージェントが参照できるように、SharePoint サイト / ファイルや Teams チャネル / グループチャット / 会議などをナレッジとして追加します。

6. [ナレッジ] セクションで [ナレッジの追加] をクリックし、以下のように設定します。

   - **ファイルを直接アップロードする場合**
     - ローカルのファイルをドラッグアンドドロップして、アップロードします。

   - **SharePoint サイト / ファイルの場合**
     - [サイト] タブから該当の SharePoint サイトやファイルを選択します。

   - **Teams チャネル / グループチャット / 会議チャットの場合**
     - [チャット] タブから該当のチャネルやチャットを選択します。

   - **会議の場合**
     - [会議] タブから該当の会議を選択します。

   ナレッジをエージェントが使用するには、エージェントを利用するユーザーがそのコンテンツにアクセスできる状態にしておく必要があります。

7. [業務コンテンツ] で参照するアプリやデータソースのオン・オフを設定します。(前の手順でコンテンツを指定したアプリは、オンになります。)

   アプリやデータソース全体を参照したい場合は、対象をオンの状態にして、特定のコンテンツは指定しません。例えば、ユーザーがアクセスできるメール全体を参照する場合は、[Outlook] をオンにします。

   一方、不要なものは、対象をオフにします。例えば、社内情報のみを使用したい場合は [Web 検索] をオフにします。

### 機能の追加

エージェントにファイルを生成させるための機能を追加します。

8. [ナレッジ] セクションの右上にある歯車アイコンをクリックします。

9. [ドキュメント、グラフ、コードを作成します] をオンにし、ダイアログを閉じます。

### スキルの追加

エージェントに実行させる特定のタスクについて、作業手順や出力形式をスキルとして定義しておくことができます。

ここでは例として、プロジェクトの月次報告を準備する業務を想定します。月次報告で確認したい進捗や成果、決定事項、課題・リスク、今後の予定などをあらかじめスキルに定義しておくことで、ユーザーが毎回細かく指示しなくても、必要な情報を決められた観点で整理して回答できるようにします。

10. [スキル] セクションで [追加] をクリックします。

11. [initiative-monthly-report.zip](./assets/initiative-monthly-report.zip) ファイルをアップロードします。

> [!NOTE]
>
> このスキルはサンプルです。対象のプロジェクトや用途に合わせて編集してみましょう。
>
> その他にも、エージェントに実行させたい特定のタスクがあれば、新しいスキルを作成して追加してみましょう。

### 推奨プロンプトの追加

推奨プロンプトを用意しておくことで、ユーザーがエージェントでできることを把握し、利用を始めやすくなります。

12. 推奨プロンプトを設定します。

    | タイトル | メッセージ |
    |------|------|
    | プロジェクトのアクションアイテム | プロジェクトで今後対応が必要なアクションアイテムをリストして |
    | 自分が対応すべき事項 | 自分が対応すべき内容をリストして |
    | 特定のトピックの状況確認 | {特定のトピック} の状況を教えて |
    | 月次報告の準備 | {開催月}の月次報告用に、{対象月}の活動内容をまとめて |

> [!NOTE]
>
> この推奨プロンプトはサンプルです。対象のプロジェクトや用途に合わせて編集してみましょう。

### その他の設定

13. エージェントのアイコンを設定します。

    上部のエージェントのアイコンをクリックし、[生成] タブが選択された状態で、[エージェントの詳細から生成する] をクリックするか、以下のようなプロンプトを入力して実行します。

    ```text
    {プロジェクト名} をイメージしたアイコンを生成して
    ```

14. 生成されたアイコンを使用する場合は、[適用] をクリックします。

> [!NOTE]
>
> ここまでの設定はサンプルです。
>
> 対象のプロジェクトや用途に合わせて、必要に応じて設定を追加したり、不要な設定を省いたりして調整してください。

### エージェントの動作を確認する

[構成] タブから [プレビュー] タブに切り替えてテストすることができますが、ここでは一度エージェントを作成し、Microsoft 365 Copilot 上で動作を確認していきます。

15. 右上の [作成] をクリックし、エージェントを作成します。

16. エージェントが作成されたら、ダイアログ上の [チャットを開始] をクリックします。

17. 以下のようなメッセージを、実際のプロジェクトや確認したい内容に合わせて調整して入力し、エージェントの動作を確認します。

    - **プロジェクトのアクションアイテムを確認する**

      ```text
      プロジェクトで今後対応が必要なアクションアイテムをリストして
      ```

    - **自分にフォーカスする**

      ```text
      自分が対応すべき内容をリストして
      ```

    - **アクションアイテムを Excel に出力する**

      ```text
      そのアクションアイテムを Excel に出力して
      ```

    - **特定の内容にフォーカスする**

      ```text
      {特定のトピック} の状況を教えて
      ```

      ```text
      先月、{特定のトピック} について、{人の名前} とやり取りしていた内容を要約して
      ```

    - **月次報告の準備**

      ```text
      10月の月次報告用に、9月の活動内容をまとめて Word ファイルにして
      ```
      エージェントが出力した Word ファイルをもとに、Copilot in PowerPoint でプレゼンテーションを作成することもできます。作成したスライドは、そのまま Copilot in PowerPoint を使って内容やデザインを調整できます。

### エージェントを編集する

実際にエージェントを使ってみると、期待した回答が得られなかったり、追加したい情報や指示が見つかったりすることがあります。

エージェントの編集画面を開き、実際の回答をもとに、設定内容を調整していきましょう。

18. [エージェントとスキル] > [{作成したエージェント}] の右側の [...] > [編集] をクリックし、エージェントの編集画面を開きます。

19. エージェントを編集したら、右上の [更新] をクリックし、エージェントを更新します。

> [!NOTE]
>
> 自分が作成したエージェントを探し、編集する場合は、[エージェントとスキル] > [新しいエージェント] をクリックし、[自分のエージェント] タブに切り替えて、[すべて表示] をクリックします。該当するエージェントで編集アイコンをクリックして、編集画面を開きます。

## 🎉 おわりに

このハンズオンでは、Agent Builder を使って、Microsoft 365 上のコンテンツを中心に情報を活用して、**自分が関わる社内プロジェクトの仕事を理解し、状況の把握やアクションアイテムの整理を支援する専用エージェント**を作成しました。

さらに、やりたいことに応じて、他の選択肢もあります。

- Power BI のデータ・レポートなど、Agent Builder で直接扱えないデータも分析・活用し、レポート作成などの成果物の出力まで含む**一連の仕事をまとめて実行させたい場合は Copilot Cowork**

  また、月次報告を例にすると、必要な情報の整理から、プレゼンテーションやドキュメントの生成までの一連の仕事を Copilot Cowork でも試し、目的や求める成果物の品質に応じて使い分けてみるのもよいでしょう。

- Microsoft 365 のコンテンツ参照にとどまらず、それ以外のサービス・データとの連携や、整理したアクションアイテムをプロジェクト管理表に登録・更新するなど、**アクションまで実行させたい場合は Copilot Studio**
